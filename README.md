# Olist E-Commerce SQL Analysis

## Project Overview

This project explores Brazilian e-commerce data from Olist using SQL to answer business questions and identify insights related to orders, customers, sellers, products, and payments.

The goal is to practice SQL-based data analysis by working with multiple related tables, validating data, and translating business questions into structured queries.

## Dataset

- **Source:** [Brazilian E-Commerce Public Dataset by Olist — Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
- **Domain:** E-commerce
- **Database:** PostgreSQL
- **Language:** SQL

## Tools & Skills

- PostgreSQL
- SQL joins and aggregations
- Common Table Expressions (CTEs)
- Window functions
- Data validation and quality checks
- Business-oriented data analysis

## Project Workflow

1. Dataset and table understanding
2. Data validation and quality checks
3. Business question analysis
4. SQL query development
5. Insights and interpretation

## Business Questions

The project investigates business questions using related e-commerce tables. Examples include:

- How many orders were fulfilled by sellers in each state?
- How does cumulative revenue vary across product categories over time?
- Which payment method is used most frequently, and what is the average order value?

## Repository Structure

The repository contains SQL analysis files organized into project phases, dataset CSV files, an ER diagram, a data dictionary, and a project report.

## Learning Objective

This project is part of my journey as a Data Analyst, strengthening my ability to understand relational datasets, write SQL queries, validate data, and answer business questions using data.
